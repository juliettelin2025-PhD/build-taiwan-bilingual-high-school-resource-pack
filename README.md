# 建立雙語高中資源包

這是一套為臺灣高中／高職雙語教育籌備者設計的開放工作包，目標不是把國外課程原封不動搬進臺灣，而是協助學校從自身學生、社區、師資與升學需求出發，建立可長期運作的雙語課程。

## 臺灣雙語教育理念

### 1. 客製化，而非一體適用

雙語課程應以學生的學科先備知識、英語程度、學習焦慮、學校類型與未來進路為起點。普通高中、技術型高中、都會學校與偏鄉學校不需要使用同一套英語比例或課程節奏。資源包將教材標為低、中、高三種語言與認知負荷，方便教師依班級狀況選擇、拆分及重組。

### 2. 在臺特色，而非複製國外學校

課程應連結臺灣的課綱核心素養、在地歷史與文化、民主公民生活、產業科技、環境與海洋議題，以及學生真實的升學與職涯選擇。IB、AP、EMI 與 ESP 是可利用的框架和工具，不是取代臺灣教育目標的品牌。

### 3. 學科學習優先，英語逐步加值

英語是理解、討論與公開表達學科內容的媒介。教師不必從第一天開始全英授課。可透過 ODIR、學科英語句型、圖像與字幕、同儕排練及有目的的跨語言溝通，讓學生從「能理解」逐步走到「能用英語說明與創作」。

## 創校常見困難與解法

| 常見困難 | 可執行解法 |
|---|---|
| 學科教師害怕用英語，擔心內容變淺 | 先完成中文學科設計，再加入少量高頻教師語言與學生句框；以共備、示範課及錄音排練累積安全感。 |
| 學生英語落差大 | 同一學習成果提供低／中／高三階材料；允許先中文建構概念，再以詞組、句框、短講逐步轉為英文。 |
| 國外教材不符合臺灣課綱與情境 | 以臺灣課綱、在地議題與學生經驗為主幹；國外材料只作案例、語言鷹架或比較素材。 |
| IB／AP 申請資訊分散且版本會變 | 只以官方目錄與流程為權威來源，記錄查核日期、版本、責任人與證據位置；正式送件前重新下載。 |
| 經費、師資與行政負荷被低估 | 建立五年預算、人力與減授鐘點表；先小規模試行，再依證據擴大；設置課程協調與資料版本管理角色。 |
| 教材著作權與帳號存取混亂 | 原檔留在有權限的校內資料庫；公開 GitHub 只放自製材料、技能、目錄及來源連結，除非授權明確允許再散布。 |
| 只追求英語比例，缺乏學習證據 | 對準 ILOs、任務與評量；觀察學生能否正確理解概念、提出證據、合作及完成真實作品。 |

## 內容

- `skills/curate-taiwan-high-school-resources`：教材下載後的分類、命名、權利查核與清單製作。
- `skills/research-taiwan-ib-ap-programs`：全臺 IB／AP 官方名錄、課程與設校證據研究。
- `skills/build-taiwan-emi-lesson-plans`：依臺灣表單製作 ODIR、低焦慮、跨科雙語教案。
- `catalog/`：不含受限原檔的教材目錄與來源紀錄。
- `samples/`：可公開分享的自製範例與設校工作表索引。

## 安裝 Skills

將需要的技能資料夾複製到個人 Codex skills 目錄，或從 GitHub 儲存庫路徑安裝。每個技能的 `SKILL.md` 都說明觸發情境、工作流程、品質標準與著作權界線。
