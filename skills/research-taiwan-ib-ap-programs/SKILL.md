# Research Taiwan IB/AP Programs

## Workflow

1. Record the research date and target school year. Treat counts, authorizations, courses, and forms as time-sensitive.
2. Use only official primary sources for authoritative facts: the IB country profile and school directory; College Board AP Central and the AP Course Ledger.
3. Enumerate every Taiwan result, not just search snippets. Capture school, location, programme/course, source URL, and check date.
4. For AP, open every school detail page and separate school-taught courses from online-provider courses.
5. For IB, distinguish PYP, MYP, DP, and CP; do not infer a programme that the directory does not show.
6. Build the evidence matrix in `references/evidence-matrix.md`. Mark an item required only when an official source supports that classification; otherwise label it recommended/local planning.
7. State clearly that public IB application PDFs are samples when the official library says the formal application is online.
8. Produce a source log and a freshness note. Never present last year's Ledger as the current year.

## Deliverables

- School inventory with filters and URLs
- Course-level detail table
- Required/recommended setup evidence matrix
- Official document index
- Research date, unresolved locations, and assumptions

Use `scripts/check_source_log.py` to detect missing source or date fields before delivery.
